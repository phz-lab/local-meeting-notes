# 会议留声 · 本地会议记录

运行在 Mac 上的本地网页工具。支持系统声音＋麦克风双路录制、停止后简体中文转写、自动保存、文字编辑和 TXT 导出。

## 环境与安装

- macOS 15 或更新版本；当前在 Apple M3 Pro、macOS 15.8.2 上验证。
- Homebrew、Apple Command Line Tools（包含 Swift；没有时运行 `xcode-select --install`）。
- 首次运行「安装依赖.command」，安装免费的 ffmpeg、whisper-cpp、uv，建立 Python 环境并编译约 150 KB 的本地采音组件。模型首次下载约 465 MB。
- 安装完成后双击「启动会议记录.command」，在 Chrome 打开 `http://127.0.0.1:8766`。
- 启动脚本会复用已经运行的服务。重启电脑后重新双击即可，不会设置开机启动。

## 开会时使用

1. 新建会议并填写名称，选择「电脑声音＋麦克风」。
2. 点击「开始录音」。首次使用时，允许 macOS 的「麦克风」和「屏幕与系统音频录制」权限。权限名称可能显示录音组件或启动它的宿主应用。若未授权，按错误提示打开「系统设置 → 隐私与安全性」后重新录制。
3. 确认「我的麦克风」「电脑声音」两个电平在对应声音出现时变化。可以戴耳机，系统声音直接来自 macOS；会议软件中不要开启外放。
4. 需要时暂停或继续，结束后点击「结束并转写」。双路原音频会保留，并在本机按时间戳对齐、混音，再使用 Whisper small 识别中文。
5. 修改生成的文字稿会自动保存，点击「导出文本」下载 TXT。

默认采集系统播放的全部应用声音，通知音也可能被录入。该功能只保存音频，不保存视频画面。若只需面对面开会，可切换「仅麦克风」使用浏览器录音。

## 保存与恢复

- 所有会议在 `outputs/会议记录/<会议编号>/`，包括元数据、文字稿和音频；源码仓库忽略整个 `outputs/` 和 `work/`。
- 双路录音持续写入本机 CAF 文件；浏览器麦克风模式每 5 秒上传一个片段，临时断开时片段缓存在当前浏览器。
- 双路录音由本地服务负责。关闭网页不会结束它，重新打开网页可找回正在进行的录音。结束会议时务必点击「结束并转写」，确认状态已经离开录音中。
- 若系统停止采音，页面会显示错误并允许转写已有文件。服务正常退出会通知采音组件停止；服务崩溃导致标准输入关闭时组件也会停止。电脑关机或系统强制中断时，最后未落盘的少量数据仍可能丢失。
- 请保持 Mac 唤醒，避免录音期间切换麦克风设备。

## 免费与本地处理

网页、采音、混音和识别都在本机执行，不调用收费 API。首次安装依赖和下载模型需要联网；之后录音及转写可离线使用。

本服务只监听 `127.0.0.1`，并检查 Host 和 Origin；不要将其暴露到公网。GitHub 仅保存代码，不能通过 GitHub Pages 提供 Mac 系统采音与本机模型服务。

默认模型路径：`~/.cache/hyperframes/whisper/models/ggml-small.bin`。可通过 `MEETING_MODEL` 环境变量设置其他兼容 whisper.cpp 的模型。已有模型会复用，避免重复下载。

## 组成

- `static/`：网页、浏览器录音、历史记录与文字编辑。
- `server.py`：本机接口、文件保存、混音和中文转写。
- `capture.py`：本地采音进程的启动、暂停、恢复、停止与异常处理。
- `native/AudioCapture.swift`：ScreenCaptureKit 系统声音与麦克风采集；按主机时间戳补齐静音，分别保存两路单声道 16 位原音频。
- `scripts/`：本机服务启动和 Swift 组件构建。

## 验证范围

已验证本机系统播放语音与麦克风分别写入文件，双路混音后可识别测试语句；API 暂停/继续/停止和中文 TXT 导出已检查；网页新页面恢复暂停会话、继续录音并结束转写已验证。原先的麦克风录音和文字编辑功能保留。

尚未逐一验证腾讯会议、飞书、Zoom 的真实通话、蓝牙耳机切换或数小时连续会议。系统接口直接采集电脑播放的声音，无需通过扬声器回录，但仍应在正式会议前做一次短录音，确认两个电平和回放都有声音。人名、数字及多人重叠讲话需人工核对。
